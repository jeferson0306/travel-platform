# ai

Engineering assistants for this platform: documentation Q&A, code
navigation, PR review support, incident/log triage, and architecture
explanation. They read the same structured context defined in
[docs/context](../docs/context) and [docs/prompts](../docs/prompts) that a
new engineer would use to ramp up.

Built in Phase 5 of [ROADMAP.md](../ROADMAP.md), after the core services and
their documentation exist for the assistants to reason over.
