# Support

This is an independent engineering project, not a commercial product with an
SLA. That said:

- **Bugs** — open an issue using the Bug report template.
- **Feature ideas / questions about design decisions** — open an issue using
  the Feature request template, or check [docs/adr](docs/adr) first; the
  answer may already be recorded there.
- **How the system works** — start with [README.md](README.md), then
  [ARCHITECTURE.md](ARCHITECTURE.md) and [docs/](docs).
